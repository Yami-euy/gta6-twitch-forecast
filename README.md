Forecast GTA VI's launch-day Twitch viewers hour by hour, from the first hour's print and 42 past game launches. A local kernel-weighted log-log regression over past launches' release-day curves, aligned on the rolling-midnight unlock, with a calibrated spread.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
